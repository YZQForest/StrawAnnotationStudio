# 秸秆标注工作台 · 3.0 画笔版

**导入图片 → 用画笔标注 → 检查完成 → 导出训练数据。** 离线运行，无需账号、Python、GPU、模型或联网。桌面版 Chrome / Edge 为主要使用浏览器。

## 下载和打开

在 GitHub 点击 **Code → Download ZIP**，完整解压。用户使用的顶层只有三项（仓库另有隐藏的 Git/CI 配置）：

| 顶层内容 | 用途 |
|---|---|
| `标注工具/` | 完整程序、说明、源码与测试；请整体保留 |
| `打开标注-Mac.command` | Mac 双击打开 |
| `打开标注-Windows.bat` | Windows 双击打开 |

不要从 ZIP 里直接运行，也不要只拷贝启动文件。启动后无需保持终端窗口开启。Windows 使用默认浏览器；若默认不是 Chrome / Edge，请用这两个浏览器打开 `标注工具/开始标注.html`。Mac 优先使用已安装的 Chrome / Edge。

macOS 若提示脚本无执行权限，直接用 Chrome / Edge 打开 **`标注工具/开始标注.html`** 即可，不需要安装软件或修改安全设置。启动文件应和完整程序文件夹放在一起；桌面上可建立替身/快捷方式，不要单独移动启动文件。

## 一张图怎么标

1. 填写姓名或固定代号，导入 JPG / PNG。建议分配 **20–50 张一批**，本批原图合计不超过 128 MB。不要一次导入全部 2097 张。
2. 点 **未标区填背景**。它只修改蓝色的未标像素，已有秸秆和不确定标记不会被覆盖。
3. 选择绿色 **秸秆**，按住鼠标描绘。标错用 **背景 / 修正** 涂回去，或撤销。笔宽按原图像素计算，缩放不改变标签分辨率。
4. 材料看不清时标 **不确定**。绿色包含可辨认的玉米茎秆、枯叶、碎片及地表残留根茎；土壤、石块、活体杂草为背景。不要填掉秸秆间的土壤孔隙，不推断地下秸秆。
5. 用 **逐区检查** 或缩放，检查细碎片、边界和孔隙。检查整幅后勾选声明，点 **完成，下一张**。仍有未标像素时不能提交完成。
6. 点 **导出数据包**。得到一个 ZIP，完成项和草稿同时保留，草稿与正式训练标签隔离。把整个 ZIP 交给负责人。

常用快捷键：`1` 秸秆、`2` 背景修正、`3` 不确定；空格拖动；Ctrl/⌘+滚轮缩放；`[` / `]` 调笔宽；Ctrl/⌘+Z 撤销、Ctrl/⌘+Shift+Z 重做；Tab 切换原图。

“进度与帮助”中仅保留恢复、批次切换、新建批次、备注及少数特殊区域处理。人物、工具等非地面区域才可排除；阴影或材料难判应标不确定，不能通过排除来美化覆盖率。

## 导出什么，后面怎么用

**日常只需要看 `summary.csv`，训练读取其中 completed 行对应的 `image_path` 和 `training_mask_path`。** 不要按目录顺序配对，也不要把所有 images 都当作完成标签。

| 导出内容 | 作用 |
|---|---|
| `images/` | 原始图片，保留原文件字节、不缩放 |
| `training_masks/` | 完成项的单通道 uint8 PNG：0 背景、1 秸秆、255 忽略 |
| `human_masks/` | 可复核人工材料标签：0 背景、255 秸秆、128 不确定 |
| `valid_roi/` | 有效地面掩膜：255 有效、0 排除 |
| `summary.csv` | 图片和标签路径、完成状态、覆盖率及上下界、视频/帧/时间 |
| `metadata/`、`manifest.json` | 来源、标注者、像素统计、版本、检查声明、SHA-256；支持恢复和追溯 |
| `drafts/`、`draft_training_masks/` | 未完成标注，仅供继续编辑，不可用于正式训练 |
| `START_HERE.txt` | 数据编码及交付说明 |

不再导出重复的 `annotations.csv` 和第二份 README，不生成热力图、叠加展示图或伪密度真值。

训练时设置 `ignore_index=255`（或等效忽略逻辑）。标签缩放只能用最近邻插值；标签和原图必须采用一致的几何变换。有争议和排除的像素不能直接改成背景。

覆盖率 = 有效地面内秸秆像素 / 有效地面像素 × 100%。不确定像素仍在分母中：有不确定或未标时，`coverage_pp` 留空，输出上下界，空值不是 0。**标注完成不等于独立复核正确。** 工具不会自动划分训练/验证/测试集，也不把批次当作独立地块。

## 保存、恢复和旧版升级

- 自动保存位置是**当前浏览器的本地缓存**，并非图片文件夹。结束前一定导出 ZIP；文件位移、浏览器更换、隐私模式或清理缓存可能影响恢复。
- 换电脑：打开工具 → 进度与帮助 → 恢复已导出的 ZIP。恢复为独立批次，不覆盖当前批次。
- 新的一批：先导出，进度与帮助 → 填标注者 → 新建一批。旧批次可从下拉框切回。
- 从 v2 升级：**先在旧工具导出完整 ZIP，再在新版恢复。** 网页路径变化后不要依赖原缓存自动出现。保持 `straw-annotation/2` 数据编码兼容；旧版单张掩码导入入口已移除。
- 导出采用无损 PNG；ZIP 上限 256 MB，以限制浏览器内存占用。原图较大时请减小批次。保存失败会明确提示，不会把失败显示为“已保存”。

## 时序研究的图片来源

在“进度与帮助”可关联抽帧工具的 `metadata.csv`。清单按 `output_filename`（也接受 `original_file_name` 或 `file_name`）与本批文件名精确匹配，同名歧义会拒绝关联。支持 `video_id`、`frame_id`、`timestamp_sec`、`source_pts`、`source_time_base`、`run_id`、`ground_group_id`；原始行完整保留。不匹配项不推断。

若导入的整个抽帧文件夹内只有一份 `metadata.csv`，工具会尝试自动关联。通常仅导入 images 子文件夹时，需手动关联上级 metadata 文件。来源字段缺失时留空。重复地面分组仍由负责人核实。

## 维护人员

普通标注者不需要运行以下命令。网页代码拆为 `index.html`、`style.css`、`app.js`，可独立检查；Python 是可选的本机保存/格式校验接口，仅用标准库。

在本文件所在目录执行：

```sh
PYTHONPATH=src python3 -m unittest discover -s tests -p test_annotation.py -v
node tests/annotation_logic.cjs
node tests/annotation_ui_smoke.cjs
```

浏览器测试另需 Playwright、pngjs 和 Chromium。GitHub Actions 运行跨平台 Python 测试和 Chromium 合成图片流程。测试边界见 [TEST_REPORT.md](TEST_REPORT.md)。

可选本机接口：`python3 annotate.py --images "抽帧目录/images" --output "标注输出目录"`，浏览器自动打开。与旧版相比 annotate.py 已移到 `标注工具/` 内，外部抽帧工具如硬编码旧位置，需更新调用路径。运行期间保留终端。默认输出用户文档目录 StrawAnnotations；纯网页入口则下载到浏览器下载目录。
